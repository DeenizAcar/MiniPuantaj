# Mini Puantaj

Günlük personel durum (GELDİ / GELMEDİ / BİLİNMİYOR) takip uygulaması.

- Web: https://deenizacar.github.io/MiniPuantaj/
- Android APK: https://deenizacar.github.io/MiniPuantaj/apk/

Kaynak `www/` klasöründedir. `main` dalına yapılan her push, GitHub Actions ile Android APK'yı (Capacitor) derler ve siteyle birlikte GitHub Pages'e yayınlar.
Veriler cihazın yerel deposunda (localStorage) tutulur.
